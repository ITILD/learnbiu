# 硬件需求
| 需求类别 | 需求项 | 技术指标要求 | 
|---------|--------|-------------|
| **GPU配置** | 单卡显存容量 / 总显存容量 / 总算力 | ≥64GB / ≥512GB / ≥2400 TFLOPS | 
| **CPU配置** | 核心数量 / 主频 | ≥64核 / ≥2.4GHz |
| **内存配置** | 系统内存容量 | ≥16TB |
| **存储配置** | 企业级SSD容量 / 企业级HDD容量 | ≥1TB / ≥80TB | 
| **网络配置** | 服务器网卡 / 配套交换机 | 支持200Gbps |
| **集群架构** | 服务器规模 | 2台、网络互联架构、200Gbps双平面/双框架 |
