# 环境准备：VSCode 安装

## 下载与安装

- 下载地址：https://code.visualstudio.com/download
- 双击 `VSCodeUserSetup-x64-版本号.exe` 安装
- 按向导默认设置完成即可

## 必备插件

| 插件 | 用途 |
|------|------|
| **Python** | Microsoft 官方 Python 支持 |
| **Chinese Language Pack** | 中文语言包（可选） |
| **Ruff** | 快速 Python 代码格式化 |

::right::
