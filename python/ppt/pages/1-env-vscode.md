# 安装 VSCode

<div class="mb-3 p-2 bg-blue-500/10 border-l-4 border-blue-500 rounded text-sm">
VSCode 是免费、跨平台的<b>代码编辑器（IDE）</b>。
</div>

## 三步装好

1. 打开 https://code.visualstudio.com/download
2. 下载并安装（Windows 双击 `.exe`；macOS 拖进“应用程序”）
3. 打开 VSCode

## 必装插件

| 插件 | 作用 |
|------|------|
| **Python** | 语法高亮、运行、调试（必装） |
| **Ruff** | 自动格式化、检查错误 |
| **Chinese Language Pack** | 中文界面（可选） |

::right::

## 安装插件

1. 点击左侧“扩展”图标（四个方块）
2. 搜索 `Python`
3. 认准 Microsoft 官方版本，点击 **Install**
4. 装好后重启 VSCode

## 打开项目

- 菜单：**文件 → 打开文件夹**
- 选择项目文件夹，而不是单独打开某个 `.py`

<div class="mt-5 p-3 bg-emerald-500/10 border-l-4 border-emerald-500 rounded text-sm">
<b>别混淆：</b>VSCode ≠ Python。VSCode 只是“写字的地方”，真正执行代码的是 Python 解释器（下一页安装）。
</div>
