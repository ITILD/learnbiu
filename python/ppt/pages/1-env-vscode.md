<div class="text-3xl font-bold mb-6">🛠️ 环境准备：VSCode 安装</div>

<div class="mt-8">
<h3 class="text-xl font-semibold mb-4">📥 下载与安装</h3>

- 下载地址：https://code.visualstudio.com/download
- 双击 `VSCodeUserSetup-x64-版本号.exe` 安装
- 按向导默认设置完成即可
</div>

<div class="mt-10">
<h3 class="text-xl font-semibold mb-4">🧩 必备插件</h3>

| 插件 | 用途 |
|------|------|
| **Python** | Microsoft 官方 Python 支持 |
| **Chinese Language Pack** | 中文语言包（可选） |
| **Ruff** | 快速 Python 代码格式化 |
</div>
