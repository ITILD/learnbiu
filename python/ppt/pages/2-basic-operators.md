# 运算符

## 算术运算符

| 运算符 | 含义 | 示例 `a=10, b=3` |
|--------|------|-------------------|
| `+` | 加 | `10 + 3 = 13` |
| `-` | 减 | `10 - 3 = 7` |
| `*` | 乘 | `10 * 3 = 30` |
| `/` | 除 | `10 / 3 = 3.33` |
| `//` | 整除 | `10 // 3 = 3` |
| `%` | 取余 | `10 % 3 = 1` |
| `**` | 幂 | `10 ** 3 = 1000` |

## 比较运算符

| 运算符 | 含义 |
|--------|------|
| `>` `<` | 大于 / 小于 |
| `>=` `<=` | 大于等于 / 小于等于 |
| `==` `!=` | 等于 / 不等于 |

::right::

## 逻辑运算符

```python
x, y = True, False

x and y   # False  与：全真才真
x or y    # True   或：有真即真
not x     # False  非：取反
```

## 赋值运算符

```python
x = 10       # 基本赋值
x += 5       # x = x + 5
x -= 3       # x = x - 3
x *= 2       # x = x * 2
x /= 4       # x = x / 4
```
