# 🎉 学习结束

## C++ 学习建议

<div class="grid grid-cols-2 gap-8 mt-8">

<div class="space-y-4">

### 📚 推荐资源

- **cppreference.com** — C++ 权威参考文档
- **《C++ Primer》** — 经典入门书籍
- **learncpp.com** — 免费在线教程
- **Compiler Explorer (godbolt.org)** — 在线编译实验

</div>

<div class="space-y-4">

### 🛠️ 实践建议

1. **多写代码**：每个概念都动手实现
2. **读优秀代码**：学习开源项目
3. **使用现代特性**：C++17/20 新语法
4. **理解内存模型**：栈 vs 堆、RAII
5. **先从智能指针开始**：避免裸指针

</div>

</div>

<div class="mt-12 text-sm opacity-60">
💡 记住：现代 C++ 不是"带类的 C"，而是全新的语言范式。
</div>
