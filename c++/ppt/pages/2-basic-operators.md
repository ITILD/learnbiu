# 基础语法：运算符

## 算术运算符

| 运算符 | 含义 | 示例 `a=10, b=3` |
|--------|------|-------------------|
| `+` | 加 | `10 + 3 = 13` |
| `-` | 减 | `10 - 3 = 7` |
| `*` | 乘 | `10 * 3 = 30` |
| `/` | 除 | `10 / 3 = 3`（整数除） |
| `%` | 取余 | `10 % 3 = 1` |

注意：整数除法结果也是整数，丢失小数！

```cpp
double x = 10 / 3;     // x = 3.0 ❌
double y = 10.0 / 3;   // y = 3.333 ✅
```

## 比较运算符

| 运算符 | 含义 |
|--------|------|
| `>` `<` `>=` `<=` | 比较大小 |
| `==` `!=` | 等于 / 不等于 |

::right::

## 逻辑运算符

```cpp
bool x = true, y = false;

x && y   // false  逻辑与：全真才真
x || y   // true   逻辑或：有真即真
!x       // false  逻辑非：取反
```

## 赋值运算符

```cpp
int x = 10;
x += 5;    // x = x + 5  → 15
x -= 3;    // x = x - 3  → 12
x *= 2;    // x = x * 2  → 24
x /= 4;    // x = x / 4  → 6
x %= 4;    // x = x % 4  → 2

// 自增 / 自减
int i = 0;
i++;       // 后置：先用后加
++i;       // 前置：先加后用
```

## 位运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `&` | 按位与 | `5 & 3 = 1` |
| `\|` | 按位或 | `5 \| 3 = 7` |
| `^` | 按位异或 | `5 ^ 3 = 6` |
| `~` | 按位取反 | `~5 = -6` |
| `<<` | 左移 | `1 << 3 = 8` |
| `>>` | 右移 | `8 >> 2 = 2` |
